# Guía práctica: estructuras de control en Python

**Universidad San Lorenzo (UNISAL)**  
**Cátedra:** Diseño de Algoritmos y Programación  
**Tema:** Estructuras condicionales y repetitivas

Este repositorio contiene las soluciones de los ejercicios P-1 a P-4 de la guía práctica. Cada ejercicio está en un archivo independiente para que se pueda ejecutar y revisar con facilidad.

## Requisitos

- Python 3.10 o superior. El ejercicio P-4 funciona también con versiones anteriores.
- Una terminal, IDLE, VS Code o PyCharm.

## Ejercicios

| Archivo | Tema | Estructuras utilizadas |
|---|---|---|
| p1_mayor_de_tres.py | Identificar el mayor de tres enteros o indicar que son iguales | if, elif, else |
| p2_tarifa_por_edad.py | Calcular el precio según la edad | if, elif, else |
| p3_promedio_calificaciones.py | Calcular la media y contar notas desde 6.0 | for, range, acumulador |
| p4_validacion_de_clave.py | Permitir hasta tres intentos de clave | while, contador, break |

## Cómo ejecutar

Desde una terminal abierta en esta carpeta, ejecutar el archivo deseado. Por ejemplo:

```bash
python p1_mayor_de_tres.py
```

En algunos equipos el comando puede ser python3 en lugar de python.

## Criterios aplicados

- Los mensajes y entradas están en español.
- Se mantienen los ejercicios separados y se usa indentación de cuatro espacios.
- En P-2, como la guía no especifica el monto de la tarifa completa, el programa solicita ese monto y aplica los porcentajes indicados.
- En P-4, la clave de demostración es python123. Se usa solo para practicar condicionales y bucles; no es un método seguro para proteger una cuenta real.
